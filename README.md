# Бірге үйренеміз · 1–4 сынып

## GitHub Pages арқылы ашу

1. ZIP архивін компьютерде ашыңыз.
2. GitHub репозиторийінің негізгі бетінде Add file → Upload files таңдаңыз.
3. Осы жинақтың ішіндегі index.html, .nojekyll және README.md файлдарын репозиторийдің түбіріне жүктеңіз. ZIP файлының өзін жүктемеңіз.
4. Commit changes арқылы сақтаңыз.
5. Settings → Pages бөліміне өтіңіз.
6. Build and deployment → Source: Deploy from a branch таңдаңыз.
7. Branch: main (немесе файлдар жүктелген тармақ), Folder: / (root) таңдап, Save басыңыз.
8. Жариялау аяқталған соң Pages бөлімінде көрсетілген сайт сілтемесін ашыңыз.

index.html ішіндегі материалдар, безендіру және тапсырмалар өзгертілмеген.
Сайтта сервер немесе қосымша орнату қажет емес.
